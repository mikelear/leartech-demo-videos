Features — built & possible

Moving spotlight ✓ built

Dim every panel, brighten the one the narration is on.

In-panel highlight ✓ built

Ring the exact line or check being discussed.

Cross-screen pins ✓ built

Arrow + tooltip on another panel, with extra text beyond the main narration.

Zoom ✓ built

Push in on the active panel and magnify the ringed element. (Videos 2, 3, 6, 7.)

Voiceover ✓ built

Toggle the browser speech API to read each beat — no audio files needed. (Videos 2, 3, 6, 7.)

Caption attention cues ✓ built

Narration pops in and reveals word-by-word to draw the eye.

Progressive reveal ✓ built

Start on one screen; bring more in — or send one out — mid-video. (Videos 6, 7.)

Typewriter terminal ✓ built

Type commands character-by-character before the output appears.

Connector lines ✓ built

An animated SVG line drawn from one panel to another. (Showcase.)

Live → after swap ✓ built

Flip a check from pending to merged on screen.

Auto-advance ✓ built

“Up next” countdown that plays the following video.

Scrubber + chapters ✓ built

Click the track to jump; each beat is a chapter.

Export to MP4 ◆ possible

Screen-record the page (OBS) or drive it headless for a shareable file.

Branded voice ◆ possible

Swap the speech API for pre-rendered audio per beat; timings already exist.

All pages are static and self-contained. Data in videos 1, 2, 4, 5 was captured live via gh and the plan API on 2026-10-17.
